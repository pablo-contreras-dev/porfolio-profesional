# Porfolio de Pablo Contreras

Web personal para presentar mi perfil como desarrollador backend junior, experiencia, proyectos, tecnologías y vías de contacto.

## Tecnologías

- React 19, TypeScript y Vite
- React Router
- GitHub Pages y GitHub Actions para compilación y despliegue

## Desarrollo local

Requiere Node.js 24 o compatible con Vite 8.

```powershell
npm ci
npm run dev
```

Para crear la versión de producción:

```powershell
npm run build
npm run preview
```

## Publicación

Cada cambio enviado a `main` compila la aplicación y publica `dist` en GitHub Pages. La web estará en:

<https://pablo-contreras-dev.github.io/porfolio-profesional/>
